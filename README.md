# Trinetri Moon Coven

A modular static website deployed from GitHub Pages.

## Project Structure

- index.html: runtime shell entrypoint
- js/partials.js: loads section partials into the shell
- js/script.js: UI behavior, animation, nav, reveal, form modal logic
- css/styles.css: all visual styles
- partials/: modular section markup files
- scripts/build-static.ps1: merges partials into index.static.html
- scripts/serve.ps1: local static server (PowerShell)
- scripts/test.ps1: smoke test script
- TESTING.md: detailed testing guide

## Runtime Modes

1. Modular runtime mode
- Use index.html
- Loads HTML sections from partials/*.html at runtime

2. Static compatibility mode
- Generate index.static.html using scripts/build-static.ps1
- No runtime partial fetching needed

## Local Development

Run local server:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\serve.ps1 -Port 5500
```

Open:
- http://localhost:5500/index.html

## Testing

Run smoke tests:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\test.ps1
```

See TESTING.md for the complete checklist.

## Build Static Version

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-static.ps1
```

This writes index.static.html.

## Form Submission UX

The contact form posts to Formspree and redirects back to this site with a success query flag.
The site then opens a themed success modal instead of showing a third-party confirmation page.

## Standardization Rules

- Keep section HTML in partials/.
- Keep styles in css/styles.css.
- Avoid inline style attributes in partials.
- Keep behavior in js/script.js.
- Keep index.html as the shell-only entrypoint.

## Deployment Notes

- This repo is static and GitHub Pages friendly.
- .nojekyll is present for consistent asset handling.
- index.static.html is generated by script and is gitignored by default.
